# Автосалон 911 — сайт

Современный сайт автосалона по продаже автомобилей с пробегом в Альметьевске.
Тёмный премиум/спорт-дизайн. Чистая статика (HTML/CSS/JS) — деплой на Vercel.

## Разделы

- **Главная** (`index.html`) — hero, услуги (Выкуп · Продажа · Трейд‑ин · Автокредит + реализация под комиссию), блок выкупа авто с заявкой, превью каталога, счастливые покупатели (фото + видео), отзывы (Яндекс.Карты / 2ГИС), контакты и карта.
- **Авто в наличии** (`catalog.html`) — каталог карточек с поиском, фильтрами и сортировкой.
- **Личный кабинет** (`admin.html`) — вход по паролю, добавление/редактирование/удаление авто, загрузка фото, отметка «Продано» и «Хит».

## Вход в личный кабинет (демо)

Пароль по умолчанию: **`avto911`** (меняется в «⚙ Настройки» внутри кабинета).

> **Демо-режим.** Авто и пароль сейчас хранятся в браузере (localStorage) —
> это витрина концепции. Добавленные через кабинет авто видны только на том
> устройстве/браузере, где их добавили.

## Следующий шаг — «живой» каталог для всех (Supabase)

Чтобы каталог был общим для всех посетителей и вход был по-настоящему защищён,
подключается **Supabase** (бесплатно): Auth (логин/пароль на сервере),
база данных (таблица авто) и Storage (фото). Фронтенд уже структурирован под
замену слоя данных `assets/js/store.js` на запросы к Supabase.

## Локальный запуск

Достаточно открыть `index.html` в браузере. Либо локальный сервер:

```bash
npx serve .
```
