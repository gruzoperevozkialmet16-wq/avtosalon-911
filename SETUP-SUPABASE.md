# Подключение Supabase — каталог для всех посетителей

Займёт ~10 минут. После этого авто, добавленные в кабинете, увидят **все**
посетители сайта, а вход в кабинет станет защищённым (логин/пароль на сервере).

## Шаг 1. Создать проект
1. Зайдите на **https://supabase.com** → войдите (можно через GitHub) → **New project**.
2. Название: `avtosalon-911`, задайте **Database Password** (сохраните его), регион — ближе к РФ (Frankfurt).
3. Дождитесь создания проекта (~1–2 минуты).

## Шаг 2. Создать таблицу и хранилище
1. Слева **SQL Editor** → **New query**.
2. Скопируйте содержимое файла [`supabase/setup.sql`](supabase/setup.sql) целиком, вставьте и нажмите **Run**.
3. Должно быть `Success`. Это создаст таблицу авто, политики доступа, бакет для фото и 6 примеров.

## Шаг 3. Создать администратора (вход в кабинет)
1. Слева **Authentication** → **Users** → **Add user** → **Create new user**.
2. Укажите email и пароль (например `admin@avtosalon911.ru` + надёжный пароль). Включите «Auto Confirm User».
3. Это и будет логин/пароль для входа на `/admin`.

## Шаг 4. Дать мне два публичных ключа
Слева **Project Settings** → **API**. Пришлите мне:
- **Project URL** — вида `https://xxxxxxxx.supabase.co`
- **anon public** ключ — длинная строка, начинается с `eyJ...`

> Эти два значения **публичные и безопасны** для сайта — доступ к данным
> ограничивают политики RLS из шага 2. Секретный `service_role` ключ —
> **никому не присылайте и на сайт не ставьте.**

## Что дальше
Я впишу URL и ключ в `assets/js/config.js`, задеплою — и каталог станет живым.
Вы заходите на `/admin` под созданным email/паролем и добавляете авто с фото —
их сразу видят все посетители.

---

### Как это устроено (кратко)
- **Таблица `cars`** — все автомобили. Читать может каждый, изменять — только вошедший админ.
- **Бакет `car-photos`** — фотографии авто (публичные ссылки).
- **Supabase Auth** — вход по email/паролю; сессия хранится безопасно.
- Файл `assets/js/store.js` сам переключается: есть ключи → Supabase, нет → демо (localStorage).
